# Synthetic SIH 26013 Dataset

**All content is FICTIONAL. No real parcel, owner, address or place
is represented anywhere in this dataset.**

Generated by `generate_dataset.py` for demonstrating multi-source
geospatial integration (SIH problem 26013).

## Layout

```
inputs/           # department copies with injected errors -> feed to matcher
evaluation_only/  # answer key -> NEVER feed to matcher
```

## CRS

- Projected: `EPSG:32643` (metres)
- Browser export: `EPSG:4326` (degrees)

## Reproducibility

- Seed: `20260213` — re-running yields identical data.
- Every file carries `synthetic: true` in the manifest.

## Ingestion notes
- legacy_parcels_no_crs.geojson is an intentionally nonstandard GeoJSON fixture:
  projected coordinates with unknown source CRS. Quarantine until explicit confirmation.
- Ground-truth observations are polygon observation areas (0.5 m buffers), not points.
- GNSS easting/northing use EPSG:32643 and metres. Survey date is unknown.
- Extracted building acquisition dates: T1 2024-11-15; T2 2025-11-20.
- GNSS reported accuracy is not an independently measured absolute accuracy.
